# Preprocesamiento de Ciencia de Datos

## Objetivo
Este proyecto tiene como finalidad implementar técnicas de limpieza, transformación y preprocesamiento de datos utilizando la librería Pandas en Python, asegurando que la información sea apta para modelos de análisis estadístico y machine learning.

## Estructura básica de carpetas
- `.github/workflows/`: Archivos de configuración para automatización (CI/CD).
- `.gitignore`: Especificación de archivos que Git debe ignorar.
- `preprocesamiento.py`: Script principal con la lógica de limpieza de datos.
- `DOCUMENTACION.md`: Manual técnico detallado del proceso.
- `README.md`: Descripción general del proyecto.
